# Allen's News

Mobile Progressive Web App for news aggregation, briefings, and monitoring.

## Categories
- Iran / Middle East
- Markets
- Geopolitics
- Business

## Install as mobile app
1. Open the GitHub Pages URL in Safari (iOS) or Chrome (Android).
2. Add to Home Screen.
3. Launches in standalone mode.

Data is currently static with recent headlines. Update `app.js` to refresh content.
